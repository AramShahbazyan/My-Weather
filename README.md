# Weather App

A simple weather app. Type a city name and see the current weather.

- Frontend: plain HTML/CSS/JS (no build step, no framework)
- Backend: one Netlify serverless function that securely proxies
  [WeatherAPI.com](https://www.weatherapi.com/) so the API key is never
  exposed to the browser
- Deployment: Netlify

See `SETUP.md` for step-by-step setup instructions, and `CLAUDE.md` for
project/developer notes.
